# mein-app-datenschutz

Verwaltung von In-App-Käufen und Abonnements

Unsere App verwendet RevenueCat, einen Dienst der RevenueCat, Inc., USA, zur Verwaltung von In-App-Käufen und Abonnements.

RevenueCat verarbeitet dabei insbesondere Informationen zur Kaufhistorie, zum Abonnementstatus und zur App-Nutzerkennung. Je nach Konfiguration können weitere Informationen übertragen werden.

Die Verarbeitung dient der Überprüfung von Käufen, der Freischaltung kostenpflichtiger Funktionen und der Auswertung von Abonnements.

Weitere Informationen findest du in der Datenschutzerklärung von RevenueCat.
